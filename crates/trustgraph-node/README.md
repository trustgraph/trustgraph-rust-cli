# @trustgraph/trustgraph

[Trust Graph](https://trustgraph.net) as a native Node.js module (napi-rs).
Use it for heavy work in Node, including Convex Node actions via
`externalPackages`. Same API as `@trustgraph/trustgraph-wasm`; see the
[types](../../bindings/trustgraph.d.ts) and the [architecture](../../doc/architecture.md).

```sh
npm ci && npm run build:node && npm run test:node   # from the repo root
```
