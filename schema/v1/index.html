Terms

TrustAtomCredential

https://trustgraph.net/ns#TrustAtomCredential · class, subclass of cred:VerifiableCredential

A Verifiable Credential in which the issuer states that it trusts the credential subject, about content, to the degree value. Comparable to CAIP-261 PeerTrustCredential and to an RFC 7071 reputon.

content

https://trustgraph.net/ns#content · property, range xsd:string

What the trust is about: a topic, comma-separated tags, or a URI. Comparable to CAIP-261 scope, a DIF Trust Establishment topic, a LinkedClaims aspect, schema:reviewAspect and the reputon assertion.

value

https://trustgraph.net/ns#value · property, range xsd:decimal

How much the issuer trusts the subject: from -1 (full distrust) through 0 (neutral) to 1 (full trust), written as a canonical decimal string with at most nine decimal places ("0.8", never 0.8 or "0.80"). Comparable to CAIP-261 level and to schema:ratingValue with worstRating −1 and bestRating 1; a reputon rating is (value + 1) / 2.

extra

https://trustgraph.net/ns#extra · property, range rdf:JSON (@json)

Application-specific fields, as a JSON object with string values. Opaque to RDF, so its keys never become undefined terms.

replaces

https://trustgraph.net/ns#replaces · property, range IRI (@id)

The credential this one supersedes, as ipfs:// and its credential ID (a CIDv1, bafkrei…). Only effective when both credentials have the same issuer. Comparable to CAIP-261 previousVersion.

The context

Served at https://trustgraph.net/ns/v1 as application/ld+json. Verifiers bundle it and never fetch it.

{
  "@context": {
    "@version": 1.1,
    "@protected": true,
    "TrustAtomCredential": "https://trustgraph.net/ns#TrustAtomCredential",
    "content": "https://trustgraph.net/ns#content",
    "value": {
      "@id": "https://trustgraph.net/ns#value",
      "@type": "http://www.w3.org/2001/XMLSchema#decimal"
    },
    "extra": {
      "@id": "https://trustgraph.net/ns#extra",
      "@type": "@json"
    },
    "replaces": {
      "@id": "https://trustgraph.net/ns#replaces",
      "@type": "@id"
    }
  }
}
